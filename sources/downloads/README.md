# Локальные копии документов

Локальные копии для исследовательской работы скачаны 21.11.2026 с официальных сайтов NASA и FEMA. Канонические ссылки и редакции записаны в [каталоге](../catalog.md). Перед практическим применением или дальнейшим распространением проверьте актуальность, уведомления ведомства и условия конкретного документа.
