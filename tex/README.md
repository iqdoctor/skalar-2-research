# TeX-воспроизведение методических материалов СПУТНИК / СКАЛАР-2

Основной файл — [`spuntik-skalar-methodology.tex`](spuntik-skalar-methodology.tex), готовый результат — [`spuntik-skalar-methodology.pdf`](spuntik-skalar-methodology.pdf). Он включает разделы 6.3–6.4 книги 1996 года (печатные страницы 111–118), приложение 2 «Система СПУТНИК» (страницы 173–187; перепечатка в томе 5, страницы 111–125), приложение 3 о СКАЛАР-2 (страницы 187–189; том 5, страницы 126–129), поисковый OCR самостоятельных текстов S-02, страницы 11–110, и полные факсимиле S-02, страницы 11–129, и S-01, страницы 111–118. В TeX набраны строка плана и формы П.1–П.9; формы и схемы снабжены источниковыми ссылками. Контрольные суммы оригиналов перечислены в [реестре](../sources/primary-source-register.md).

## Сборка

Нужны XeTeX/Tectonic и шрифты PT Serif, PT Sans, PT Mono и Arial Unicode MS. Последний нужен для редких Unicode-символов в поисковой выгрузке тома 5. Из этой папки:

```sh
tectonic -X compile spuntik-skalar-methodology.tex
```

Локальная сборка проверена Tectonic на macOS; Tectonic обращается к абсолютным путям системных шрифтов. Для совпадающей пагинации требуются те же PT Serif, PT Sans, PT Mono и Arial Unicode MS. Проверенный PDF содержит 230 страниц: 103 формата A4 и 127 факсимильных страниц формата A5. Смешанный размер намеренный: `fitpaper=true` сохраняет геометрию исходных сканов; для печати учитывайте разные форматы страниц.

## Сверка и ограничения

- Транскрипция [`source-transcription-book-1996-111-118.txt`](source-transcription-book-1996-111-118.txt) визуально сверена по страницам S-01; исходная выгрузка сохранена отдельно. S-02, страницы 11–110, остаётся сырым OCR-поисковым слоем; страницы 11–129 целиком добавлены в конец PDF как факсимиле, поэтому оригинальные схемы, таблицы и подписи доступны без потерь. В текстовой транскрипции S-02, страницы 111–129, оставлены процедурные абзацы; повреждённые OCR-блоки таблиц вынесены из набранного текста, а формы П.1–П.9 восстановлены по сканам. Страницы S-01 111–118 также включены в полный факсимильный раздел.
- Формы П.4–П.8 набраны в альбомной ориентации для читаемости; это меняет расположение и масштаб относительно книжных страниц. Для исходной компоновки используйте включённые факсимиле.
- Для рис. П.1–П.3 сделаны векторные версии. Рис. П.4 дан как контурная трассировка 600-dpi скана S-02, с. 129; рядом в PDF оставлено факсимиле для проверки узлов, направлений и штриховок. Полные исходные страницы приложены в конце PDF. Исходный SVG и параметры трассировки перечислены в [описании графических файлов](assets/README.md).
- В исходной таблице П.5 напечатано «СРЦ», хотя текст рядом говорит «СРП»; расхождение отмечено, а не исправлено.
