# Графические файлы методики

`source-P4.png` — контрольное изображение рисунка П.4 из S-02, печатная с. 129. Полная страница доступна в оригинальном PDF и в факсимильном разделе TeX-PDF.

`figure-P4-vector.svg` — исходный векторный файл трассировки; `figure-P4-vector.pdf` — тот же рисунок в формате для включения в TeX. Контуры получены из S-02, с. 129: страницу отрисовали при 600 dpi, затем обрезали до прямоугольника 3300 × 2650 px с начальным смещением 150 px сверху и 190 px слева. Potrace 1.16 преобразовал чёрно-белые контуры командой `potrace -k 0.1 -t 0 -O 0.01 -n`. Параметры и смещение фиксируют способ получения, а не авторскую редакцию рисунка.

Трассировка сохраняет расположение узлов, стрелки, границы и видимое заполнение секторов. Из-за порогового преобразования она не сохраняет серые пиксели сглаживания скана; факсимиле оставлено рядом как контрольный источник.
